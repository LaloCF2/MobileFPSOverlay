¡Monitorea el rendimiento de tu juego en la base oficial! **FNF V-Slice Mobile FPS Counter** es un componente optimizado diseñado específicamente para mostrar un contador de fotogramas por segundo (FPS) en la versión **V-Slice** de **Friday Night Funkin'**. 

Este script ha sido completamente adaptado y pulido para un rendimiento óptimo en dispositivos **móviles**, manteniendo compatibilidad total con las builds de **escritorio (PC)**.

## ✨ Características Principales

*   📱 **Optimización para Móviles:** Diseñado con un consumo mínimo de memoria para asegurar que el recolector de basura (*Garbage Collector*) de Haxe en móviles no genere tirones (*lag*).
*   ⚡ **Precisión Real-Time:** Lectura exacta de fotogramas directamente del ciclo de renderizado.
*   🎨 **Estética V-Slice:** Se integra de forma limpia en la pantalla sin obstruir las notas, los inputs táctiles ni el HUD oficial de la Funkin' Crew.
*   🔧 **Multiplataforma Nativo:** Funciona perfectamente tanto en Android/iOS como en tus builds locales de PC.
